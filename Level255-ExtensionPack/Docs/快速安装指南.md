# 快速安装指南

## 🚀 5分钟快速安装

### 前提条件
- ✅ AzerothCore 3.3.5 服务器
- ✅ 编译环境（CMake, Visual Studio）
- ✅ MySQL 数据库
- ✅ WoW 3.3.5 客户端

---

## 📝 安装步骤

### 1️⃣ 修改源代码（1分钟）

打开文件：
```
src/server/shared/DataStores/DBCEnums.h
```

第 39 行，修改：
```cpp
#define MAX_LEVEL    255  // 原值是 100
```

---

### 2️⃣ 重新编译（10-30分钟）

```powershell
cd var/build
cmake ../..
cmake --build . --config RelWithDebInfo --target worldserver
```

---

### 3️⃣ 导入数据库（1分钟）

```sql
mysql -u acore -pacore acore_world < Database/Player225Stats.sql
```

---

### 4️⃣ 修改配置（30秒）

编辑 `worldserver.conf`：
```ini
MaxPlayerLevel = 255
```

---

### 5️⃣ 安装客户端插件（30秒）

复制文件夹：
```
ClientAddon/CustomXPBar/
→
游戏安装目录/Interface/AddOns/
```

---

### 6️⃣ 重启服务器（1分钟）

重启 worldserver

---

## ✅ 完成！

进入游戏测试：
```
.level 255
```

应该成功！属性会暴涨！
